# Fancybox2 to Fancybox3 for image gallery

*Published on 2017-05-12 by System Design | [https://rishijeet.github.io/blog/fancybox2-to-fancybox3-for-image-gallery/](https://rishijeet.github.io/blog/fancybox2-to-fancybox3-for-image-gallery/)*

I recently migrated my image gallery to Fancybox3 from Fancybox2. Fancybox3 has some of the advantages over its previous version.
The important one I like is the fact that you have to code less.

- Import the javascript

- Wrap the images with class and the work is done.

- It supports the image security too. 

Personally, I like the masonry style more and working on moving towards its soon. Still exploring the feasibility.
The details on the masonry grid could be found [here](https://masonry.desandro.com/).
